# Gasem для VS Code

Подсветка синтаксиса, проверка ошибок прямо при наборе, переход к объявлению,
подсказки и автодополнение, сниппеты и автоотступы для файлов `.gsm`.

Проверку ошибок и подсказки даёт языковой сервер — программа `gasem` (Go-версия,
команда `gasem lsp`). Расширение находит её в `PATH`; другой путь можно указать
в настройке **gasem.path**. Без программы `gasem` работают подсветка, сниппеты
и отступы.

## Установка

Готовый пакет — `gasem-0.1.0.vsix` (его собирает `go/release.sh` в `dist/`).
В VS Code: панель расширений (`Ctrl+Shift+X`) → `⋯` вверху → **Install from
VSIX…** → выбрать файл. Или из терминала:

```sh
code --install-extension gasem-0.1.0.vsix
```

Собрать пакет самому (нужен Node.js):

```sh
cd editors/vscode
npx @vscode/vsce package --skip-license
```

Без пакета: скопировать эту папку в каталог расширений и перезапустить VS Code:

```sh
# Linux / macOS
cp -r editors/vscode ~/.vscode/extensions/gasem-0.1.0
# Windows (PowerShell)
Copy-Item -Recurse editors\vscode $env:USERPROFILE\.vscode\extensions\gasem-0.1.0
```

## Что есть

- **ошибки и предупреждения при наборе** — те же сообщения, что у компилятора,
  с подчёркиванием нужного места; если файл подключается через `include`
  (как модули GasemOS), проверяется вся программа целиком, включая ещё не
  сохранённые изменения в открытых файлах; ошибка внутри макроса видна и в
  строке вызова;
- **переход к объявлению** (F12, Ctrl+клик) — метки, локальные метки `.x`,
  константы, процедуры, макросы, структуры и поля (`Point.x`), локальные
  переменные `proc`; **поиск использований** (Shift+F12);
- **подсказка при наведении** — значение константы, адрес метки, размер
  структуры, объявление процедуры или макроса, описание команды или регистра;
- **автодополнение** — имена из всей программы, локальные переменные текущей
  `proc`, команды, регистры, ключевые слова;
- **структура файла** (Outline, Ctrl+Shift+O) — процедуры с локальными
  переменными, структуры с полями, метки с локальными метками;
- **выравнивание** (Shift+Alt+F) — то же, что `gasem fmt`;
- кнопки **«Собрать»** и **«Запустить в QEMU»** над редактором (`gasem build`,
  `gasem run` для текущего файла);
- подсветка команд (включая `nxtb`, `chk`, `jf…`), регистров (и 64-битных),
  меток, констант, данных (`b:`, `s:`, `w-N` …), строк, чисел, `do`/`let`
  (выражение внутри кавычек подсвечивается как код), `if`/`while`/`for`,
  `macro`/`proc`/`struct`/`at`, разделителя ` - `;
- сниппеты: `boot` (загрузочный сектор), `if`, `ifelse`, `while`, `for`,
  `repeat`, `let`, `do`, `proc`, `str`;
- автоотступ внутри блоков и сворачивание блоков;
- `Ctrl+/` комментирует строки через `;`.

## Для разработчиков

Грамматика генерируется из таблиц компилятора, чтобы подсветка знала те же
команды и регистры:

```sh
python3 editors/vscode/generate.py
```

Расширение и языковой сервер проверяются без самого VS Code: `extension.js` —
с подставным модулем `vscode`, сервер — через `vscode-jsonrpc` (ту же
библиотеку, через которую VS Code общается с серверами):

```sh
cd editors/vscode
npm install
node test-extension.js путь/к/gasem
```

Грамматику — тем же движком, что использует VS Code:

```sh
cd editors/vscode
npm install --no-save vscode-textmate vscode-oniguruma
node test-grammar.js ../../examples/hello.gsm
```
