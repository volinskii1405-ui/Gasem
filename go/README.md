# Gasem на Go

Вторая реализация компилятора Gasem — на Go. Это одна программа `gasem` без
зависимостей: Python не нужен. Готовые сборки есть для Windows, Linux и macOS
(x86-64 и ARM64).

Ведёт себя так же, как Python-версия: те же байты машинного кода, те же
сообщения об ошибках (с подсказками «может быть, …» и указателем `^`), тот же
листинг и карта символов, те же команды `run`, `debug` и `fmt`, даже
сообщения об ошибках в аргументах командной строки. Работает примерно в 6 раз
быстрее: GasemOS собирается за 27 мс вместо 170 мс.

## Установка

Скачать архив для своей системы (`gasem-0.2.0-<система>-<процессор>`),
распаковать и положить `gasem` (`gasem.exe`) в папку из `PATH`. В архиве также
справочник языка `gasem.txt`, примеры и папка `gasemos` — исходники GasemOS и
готовый образ диска (`qemu-system-i386 -drive format=raw,file=gasemos/gasemos.img`).

Или через Go (1.21+):

```sh
go install github.com/volinskii1405-ui/Gasem/go/cmd/gasem@latest
```

Или собрать из исходников:

```sh
cd go
go build -o bin/ ./cmd/gasem        # → go/bin/gasem (в Windows — gasem.exe)
bin/gasem ../examples/hello.gsm
```

Архивы для всех систем сразу: `go/release.sh` → папка `dist/`.

## Устройство

Каждый файл повторяет модуль Python-версии:

| Go                        | Python               | Что делает                                         |
|---------------------------|----------------------|----------------------------------------------------|
| `gasem/lexer.go`          | `gasem/lexer.py`     | токены, разделитель ` - `                          |
| `gasem/parser.go`         | `gasem/parser.py`    | строки → операторы, операнды, выражения, `do`      |
| `gasem/highlevel.go`      | `gasem/highlevel.py` | `if`/`while`/`for`/`repeat`, условия               |
| `gasem/let.go`            | `gasem/highlevel.py` | `let` → команды x86                                 |
| `gasem/expr.go`           | `gasem/expr.py`      | вычисление выражений                               |
| `gasem/assembler.go`      | `gasem/assembler.py` | многопроходная сборка, данные, листинг             |
| `gasem/x86.go`            | `gasem/x86.py`       | кодирование команд x86                             |
| `gasem/hints.go`          | `gasem/hints.py`     | подсказки при опечатках                            |
| `gasem/format.go`         | `gasem/fmt.py`       | `gasem fmt`                                        |
| `gasem/debug.go`          | `gasem/debug.py`     | `gasem debug`: QEMU + GDB                          |
| `gasem/errors.go`         | `gasem/errors.py`    | сообщения об ошибках                               |
| `cmd/gasem/`              | `gasem/cli.py`       | командная строка                                   |
| `gasem/pyutil.go`, `gasem/difflib.go` | —        | строки, Unicode и diff — так же, как в Python      |
| `cmd/gasemapi/`           | —                    | мост для тестов (JSON)                             |

Числа, как и в Python-версии, не ограничены по размеру (`math/big`):
`X = 1 << 100` — допустимая константа, а «не помещается в 16 бит» проверяется,
когда число записывается в команду или данные.

Компилятор можно использовать как библиотеку:

```go
import "github.com/volinskii1405-ui/Gasem/go/gasem"

res, errs := gasem.CompileSource("og 0x7C00\njmp $\n&& 510-($-$$) b: 0\nw: 0xAA55", "", "")
if errs != nil {
    fmt.Println(errs.Format())
}
os.WriteFile("boot.bin", res.Code, 0o644)
```

## Как проверено, что версии совпадают

- **Весь набор тестов Python-версии** запускается против Go-версии:

  ```sh
  GASEM_IMPL=go python3 -m pytest tests
  ```

  Это сверка с NASM (460+ форм команд), запуск примеров и `let` в эмуляторе
  x86, GasemOS в QEMU с файловой системой, отладчик GDB, `fmt`, подсказки,
  командная строка — 120 тестов и 1139 подтестов.
- **`tests/test_go.py`** сравнивает обе версии на всех программах из
  репозитория, на 1500 случайных фрагментах с «опечатками» и на пограничных
  случаях (огромные числа, Unicode, неверный UTF-8 в строках): машинный код,
  листинг, символы, карта строк для отладчика, предупреждения и тексты ошибок
  должны совпадать символ в символ. Работает в обычном прогоне тестов, если
  установлен `go`.
- При переносе так же сверялись 1359 программ из тестов и около 225 000 их
  мутаций, 48 сценариев командной строки (коды выхода, вывод, файлы) — ни
  одного расхождения.
- Свои тесты Go-пакета: `cd go && go test ./...`.
