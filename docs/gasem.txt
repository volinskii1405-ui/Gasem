1. ОБЩЕЕ
--------
Gasem — компилируемый язык для написания загрузчиков и системного ПО.
Синтаксис в стиле ассемблера x86. Компилятор gasem переводит программу
прямо в машинный код x86 (16 и 32 бит) — в двоичный файл, который
выполняет процессор. Ни Python, ни ассемблер для запуска программы
не нужны.

Компилятор есть в двух реализациях, которые работают одинаково (те же
байты, те же сообщения об ошибках, те же команды):
    на Go       одна программа gasem (gasem.exe) без зависимостей —
                для Windows, Linux и macOS
    на Python   пакет gasem, нужен Python 3.8+: python3 -m gasem ...

Исходник       текстовый файл в UTF-8, расширение .gsm
Строка         одна команда на строку
Комментарий    от ; до конца строки
Регистр букв   команды, регистры, директивы — без разницы (MOV = mov);
               имена меток — с учётом регистра (Msg и msg — разные)

Разделитель операндов: - (дефис, окружённый пробелами), не запятая.

    mov ax - bx            два операнда
    imul ax - bx - 10      три операнда
    mov ax - -1            второй операнд — число -1

Дефис БЕЗ пробелов — это минус: 510-($-$$).
Внутри скобок ( ) и [ ] дефис всегда минус: [bx - 2], (a - b).
Там, где операндов нет (константы, условия if/while), " - " — тоже минус:
SIZE = end - start.

Регистры:
    8 бит      al cl dl bl ah ch dh bh
    16 бит     ax cx dx bx sp bp si di
    32 бита    eax ecx edx ebx esp ebp esi edi
    сегменты   es cs ss ds fs gs
    управление cr0 cr2 cr3 cr4
    отладка    dr0 ... dr7


2. КОМПИЛЯТОР И КОМАНДНАЯ СТРОКА
--------------------------------
Go-версия: программа gasem из архива для своей системы (или
go install github.com/volinskii1405-ui/Gasem/go/cmd/gasem@latest).
Python-версия: python3 -m gasem ..., после pip install . — команда gasem.

gasem файл.gsm                собрать (то же: gasem build файл.gsm)
gasem run файл.gsm            собрать и запустить в QEMU
gasem debug файл.gsm -b метка запустить в QEMU под отладчиком GDB
gasem fmt файлы.gsm           выровнять оформление

Параметры сборки:
-o файл        выходной файл (по умолчанию — имя исходника с .bin)
-l файл        листинг: адрес, байты машинного кода, строка исходника
-m файл        карта символов: адрес и имя каждой метки
-w             не показывать предупреждения
-q             не печатать сообщение об успешной сборке
--run          после сборки запустить в QEMU
-V             версия компилятора

Пример:
    gasem boot.gsm -o boot.bin
    qemu-system-i386 -drive format=raw,file=boot.bin

Строки кодируются в UTF-8.


4. МЕТКИ И КОНСТАНТЫ
--------------------
start:                  метка — адрес следующей команды
loop: dec cx            метка и команда на одной строке
msg s: "Hello"          переменная: имя без двоеточия перед данными
.next:                  локальная метка — принадлежит последней глобальной

- Ссылаться можно и вперёд, и назад.
- Локальная метка .next после глобальной print на самом деле называется
  print.next — так к ней можно обратиться из другого места программы.
- В именах можно использовать буквы любого алфавита (и кириллицу),
  цифры, _ и точку.


5. ДИРЕКТИВЫ
------------
og 0x7C00             адрес загрузки (org). Один раз, до первой команды
b 16                  16-битный режим (bits)
b 32                  32-битный режим. Режим можно менять по ходу программы
align N               выровнять адрес до кратного N (заполнение — nop)
align N - байт        выровнять, заполнив указанным байтом
include "файл.gsm"    вставить текст другого файла
incbin "файл"         вставить двоичный файл как есть

                      вставить часть двоичного файла

Пути в include и incbin считаются от папки текущего исходника.


6. КОМАНДЫ
----------
Команды Gasem:

mov ax - 1        переместить
xor ax - ax       исключающее ИЛИ
int 0x10          прерывание
nxtb              следующий байт: al = [si], si = si + 1   (lodsb)
nxtw, nxtd        следующее слово / двойное слово          (lodsw, lodsd)
chk al - al       проверка: И без записи результата         (test)
jfnz метка        переход, если не ноль                     (jnz)
jmp $             безусловный переход; $ — эта же строка (вечный цикл)

Условные переходы: jf + условие.
    jfz  jfnz  jfe  jfne     ноль / не ноль, равно / не равно
    jfc  jfnc                перенос есть / нет
    jfa  jfae  jfb  jfbe     больше / не меньше / меньше / не больше
                             (без знака)
    jfg  jfge  jfl  jfle     то же со знаком
    jfs  jfns  jfo  jfno  jfp  jfnp
                             знак, переполнение, чётность
    Синонимы: jfna jfnb jfnae jfnbe jfng jfnl jfnge jfnle jfpe jfpo

Стандартные имена x86 (lodsb, test, jnz ...) тоже работают.

Остальные команды x86:
пересылка          mov xchg lea movzx movsx lds les lss lfs lgs
                   push pop pusha popa pushad popad pushf popf pushfd popfd
арифметика         add adc sub sbb cmp inc dec neg mul imul div idiv
                   cbw cwde cwd cdq daa das aaa aas
логика и сдвиги    and or xor not test shl sal shr sar rol ror rcl rcr
биты               bt bts btr btc bsf bsr bswap set<усл> cmov<усл>
переходы, вызовы   jmp call ret retf iret iretd j<усл> loop loope loopne
                   jcxz jecxz int int3 into enter leave
строковые          movsb/w/d cmpsb/w/d stosb/w/d lodsb/w/d scasb/w/d
                   insb/w/d outsb/w/d
префиксы           rep repe repz repne repnz lock, сегменты es cs ss ds fs gs
порты              in out
флаги              cli sti cld std clc stc cmc lahf sahf
системные          lgdt lidt sgdt sidt lldt sldt ltr str lmsw smsw invlpg
                   clts hlt cpuid rdtsc rdmsr wrmsr wbinvd invd ud2 nop
                   pause wait xlatb


7. ОПЕРАНДЫ
-----------
mov ax - bx                  регистр
mov ax - 0x1234              число или выражение
mov si - msg                 адрес метки
mov ax - [msg]               память по адресу
mov al - [bx+si+4]           16 бит: bx/bp + si/di + смещение
mov eax - [ebx+ecx*4+8]      32 бита: база + индекс*1/2/4/8 + смещение
mov ax - [es:di]             сегмент (можно и так: es:[di])
mov byte [bx] - 5            размер, если его не понять из регистра:
mov word [bx] - 5              byte / word / dword (коротко: b / w / d)
jmp short метка              короткий переход принудительно
jmp 0x08:pm_start            дальний переход сегмент:смещение
jmp far [ptr]                дальний переход по адресу в памяти
rep stosb                    префикс
mov cr0 - eax                управляющий регистр
mov si - "Hello"             адрес строки (раздел 14)
push eax - ebx - ecx         несколько регистров сразу
pop eax - ebx - ecx          pop снимает в обратном порядке: список тот же

Короткие формы выбираются сами: переход занимает 2 байта, если цель
близко (от -128 до +127 байт), иначе 3 (в b 32 — 5); число в add bx - 5
кодируется одним байтом и т. д. Машинный код совпадает байт в байт с NASM.


8. ПОРТЫ (АБСТРАКЦИИ)
---------------------
mov a20 - 1      включить линию A20
mov a20 - 0      выключить линию A20

Используется быстрый способ через системный порт 0x92. Регистр ax
(eax в b 32) сохраняется. mov a20 - 1 превращается в:

    push ax
    in al - 0x92
    or al - 2        бит 1 — линия A20
    and al - 0xFE    бит 0 (сброс машины) никогда не ставится
    out 0x92 - al
    pop ax


9. ДАННЫЕ
---------
b:               0 байт: только метка (буфер, растущий за конец программы)
b: "Hello"       байты по содержимому: 48 65 6C 6C 6F
b: "Hello" - 0   несколько значений через " - ": строка и нулевой байт
s: "Hello"       строка с нулём в конце (то же, что b: "Hello" - 0)
b-N              ровно N байт, заполненных нулями
b/ N: значения   ровно N байт: начало — значения, остаток — нули.
                 Инициализация обязательна, N > 0, значения не длиннее N
w:  w-N  w/ N:   то же для слов (2 байта)
d:  d-N  d/ N:   то же для двойных слов (4 байта)
q:  q-N  q/ N:   то же для 8-байтных значений (удобно для GDT)
&& N b: 0        повторение: любая строка данных или команда N раз
w: 0xAA55        слово (байты 55 AA)

Перед данными можно поставить имя переменной:
    msg s: "Hello"
    buf b-512
    count w: 0
Число, которое не помещается в элемент, — ошибка.


10. ВЫРАЖЕНИЯ
-------------
Операторы, от низшего приоритета к высшему:
    1   |
    2   ^
    3   &
    4   <<  >>
    5   +  -
    6   *  /  %
    7   унарные  -  +  ~

$$           адрес начала программы (значение og)
510-($-$$)   сколько байт осталось до сигнатуры загрузочного сектора


11. ВЫРАЖЕНИЯ do (ПРИ КОМПИЛЯЦИИ)
--------------------------------
do "выражение" - приёмник

Кавычки обязательны. Выражение вычисляется ПРИ КОМПИЛЯЦИИ, результат
кладётся в приёмник (регистр или память):
- число  -> получается mov приёмник - число;
- строка -> компилятор кладёт строку прямо в код (с переходом в обход и
            нулём в конце), а в приёмник — её адрес. Одинаковые строки
            хранятся один раз.

[msg]      всё значение переменной msg, как оно объявлено
           (строка — целиком, до нулевого байта; одно число — число)
msg        адрес
+          для чисел — сложение, для строк — склейка
           (число превращается в текст)
'текст'    строковая константа
- * / % & | ^ << >> ~    только для чисел

Примеры (msg s: "Hello", f s: "World"):
    do "4+4" - ax            ax = 8
    do "[msg]" - ax          ax -> строка "Hello"
    do "[msg] + 1" - ax      ax -> строка "Hello1"
    do "[msg] + [f]" - ax    ax -> строка "HelloWorld"
    do "msg + 2" - si        si = адрес msg + 2

Регистры в do использовать нельзя: оно вычисляется при компиляции.
Для вычислений во время работы есть let (раздел 13).


12. УПРАВЛЯЮЩИЕ КОНСТРУКЦИИ: IF, WHILE, FOR, REPEAT
--------------------------------------------------
Ветвления и циклы без ручных меток. Компилятор сам ставит сравнения,
условные переходы и служебные метки. Блоки можно вкладывать.

if al = 10                       ветвление
    call line_feed
elif al >= 'a' and al <= 'z'     elif и else необязательны
    xor al - 0x20
else
    call putc
end

while byte [esi] != 0            пока условие истинно
    inc esi
end

for ecx - 0 - 256                ecx = 0, 1, ..., 255 (конец не включается)
    call set_gate
end

for ecx - 10 - 0 - -1            ecx = 10, 9, ..., 1 (четвёртое число — шаг)
    nop
end

repeat                           тело выполняется хотя бы раз
    in al - dx
    chk al - 0x80
until zero

while 1                          бесконечный цикл
    call getchar
    break if al = 27             break — выйти из ближайшего цикла
    continue if al < ' '         continue — к следующему шагу
    call putc
end

Условия:
a = b, a != b              равно, не равно (== тоже работает)
a < b, a > b,              сравнение БЕЗ знака
a <= b, a >= b             (адреса, символы, счётчики)
signed ...                 сравнение со знаком:
                             if signed eax < 0
                             for signed ecx - -5 - 5
x                          регистр или память не равны нулю:
                             while byte [esi]
not x                      равны нулю
zero carry sign            флаг после предыдущей команды;
overflow parity              not zero, not carry ...
... and ...                несколько условий; and связывает сильнее or;
... or ...                 проверяются по порядку и не дальше, чем нужно

Слева в сравнении — регистр или память, справа — регистр, память
или число. Сравнение регистра с нулём превращается в chk r - r.

Условие в конце строки — любая команда выполняется только при условии:
    ret if carry               вместо if carry / ret / end
    inc bx if zero
    break if al = 27
    continue if not zero
    jmp .fail if eax = 0       один условный переход (test / jz)


13. LET (ВЫРАЖЕНИЯ ВО ВРЕМЯ РАБОТЫ)
---------------------------------
let приёмник - "выражение"
let "выражение" - приёмник     можно и в порядке do

do считает при компиляции, let — во время работы программы, с регистрами
и памятью. Компилятор превращает выражение в команды x86.

    let ebx - "[cur_row]*80 + [cur_col]"
    let eax - "(ebx + ecx) * (edx - 3) / esi"
    let edi - "ebx*512 + FS_DIR"
    let al - "byte [esi] - '0'"
    let signed eax - "-ebx / 2"

Можно использовать:
регистры     eax, bx, cl ...  (меньшие расширяются нулями,
             в signed — с учётом знака)
память       [x], [esi+4], byte [esi], word [bx+si]
числа        80, 'A', константы, адреса меток
операции     + - * / % & | ^ << >> ~, унарный минус, скобки

- Приёмник — регистр или память с размером: let dword [x] - "...".
- Меняется только приёмник (и флаги). Если нужны временные регистры,
  компилятор сохраняет их в стеке и восстанавливает.
- Деление и остаток — без знака (div), в signed — со знаком (idiv);
  >> — shr или sar. Умножение и деление на степень двойки становятся
  сдвигами.
- Части без регистров и памяти (FS_DIR + 512) считаются при компиляции.
- esp и sp в let использовать нельзя. Если выражение слишком сложное и
  свободных регистров не хватает, компилятор попросит разбить его на
  несколько let.


14. СТРОКИ В КОМАНДАХ И POOL
---------------------------
Строку в двойных кавычках можно писать прямо в команде. В операнд
попадёт АДРЕС строки, а саму строку (с нулём в конце) компилятор положит
в данные. Одинаковые строки хранятся один раз.

    mov si - "Hello"
    call puts - "Saved "

Куда кладутся строки:
- pool — сюда попадают строки из команд, встретившихся выше (после
  предыдущего pool). Обычно его ставят в конце кода. Можно несколько:
  в GasemOS один pool стоит в загрузочном секторе, другой — в конце ядра.
- если ниже команды pool нет, строка кладётся прямо в код, а перед ней —
  короткий переход в обход (2 байта).

'A' в одинарных кавычках — по-прежнему символ (число).
Если перепутать (mov al - "A"), компилятор подскажет.


15. ВЫЗОВ С АРГУМЕНТАМИ: CALL И ARGS
-----------------------------------
args puts - esi                 puts получает аргумент в esi
args set_pos - eax - ebx        set_pos — в eax и ebx

call puts - "Hello"             mov esi - адрес "Hello" / call puts
call set_pos - 12 - 27          mov eax - 12 / mov ebx - 27 / call set_pos
jmp puts - "Bye"                то же, но переход (хвостовой вызов)

- args можно писать где угодно — до вызова или после.
- Без args аргументы идут в eax, ebx, ecx, edx, esi, edi
  (в b 16 — ax, bx, cx, dx, si, di).
- Аргумент — число, метка, строка, регистр или память. Меньший регистр
  расширяется (movzx).
- Порядок пересылок компилятор выбирает сам, чтобы не затереть нужный
  регистр: call f - 5 - eax при args f - eax - ebx сначала делает
  mov ebx - eax. Если аргументы зависят друг от друга по кругу
  (call f - ebx - eax), будет ошибка.


16. ОШИБКИ, ПОДСКАЗКИ, ПРЕДУПРЕЖДЕНИЯ
------------------------------------
Компилятор показывает файл, строку, саму строку и место ошибки и по
возможности подсказывает, как исправить:

    boot.gsm:4: ошибка: операнды разделяются ' - ' (дефис с пробелами),
    а не запятой
        mov ax, 1
              ^

Опечатки он узнаёт (переставленные, лишние, пропущенные буквы, регистр
букв, соседняя клавиша):

    неизвестная команда 'mvo' — может быть, 'mov'?
    неизвестная команда 'nxbt' — может быть, 'nxtb'?
    неизвестное имя 'prnit' — может быть, 'print'?
    неизвестное имя 'ebz' — может быть, регистр 'ebx'?
    неизвестная переменная 'mgs' — может быть, 'msg'?

Если код не помещается в загрузочный сектор:

    отрицательное число повторений (-90): код не помещается в отведённое
    место (например, загрузочный сектор длиннее 510 байт)

Предупреждения не мешают сборке, но указывают на подозрительное:

    предупреждение: метка 'old_print' нигде не используется

(о первой метке программы — точке входа — не предупреждает).
Отключить предупреждения: параметр -w.


17. ИНСТРУМЕНТЫ
---------------
Листинг (-l): таблица «строка — адрес — байты — исходник» и список меток.

    4     00007C00  31C0              xor ax - ax
    5     00007C02  8ED8              mov ds - ax
    6     00007C04  BE127C            mov si - msg

Карта символов (-m): адрес и имя каждой метки.

Отладка: gasem debug файл.gsm -b метка
Программа запускается в QEMU остановленной, подключается GDB. Команды:
    gbreak метка      точка останова на метке
    gstep             выполнить одну строку .gsm (даже если это let
                      из нескольких команд процессора)
    gwhere            показать текущую строку
    continue, info registers, x/8xb адрес ...   обычные команды GDB
При каждой остановке печатаются строка исходника и регистры:
    => boot.gsm:7    let bx - "cx*10 + 7"
       eax=00000000  ebx=00000000  ecx=00000003  ...
Параметр --batch: без окон дойти до первой точки останова, показать
состояние и выйти. Нужны qemu-system-i386 и gdb.

Оформление: gasem fmt
    gasem fmt *.gsm           выровнять на месте
    gasem fmt --check *.gsm   только проверить
    gasem fmt --diff файл     показать изменения
Тела if/while/for/repeat сдвигаются на 4 пробела, комментарии в конце
строк выравниваются в один столбец. Меняются только пробелы.

VS Code: папка editors/vscode — подсветка синтаксиса, сниппеты (boot, if,
ifelse, while, for, repeat, let, do, proc, str), автоотступы. Установка:
скопировать папку в ~/.vscode/extensions/gasem-0.1.0 и перезапустить
редактор.


18. ПРИМЕРЫ
-----------
Загрузчик из первоначальной документации — печатает Hello:

    og 0x7C00
    b 16
    xor ax - ax
    mov ds - ax
    mov si - msg
    print:
        mov ah - 0x0E
        nxtb
        int 0x10
        chk al - al
        jfnz print
        jmp $

    msg b: "Hello" - 0
    && 510-($-$$) b: 0
    w: 0xAA55

Результат — ровно 512 байт с сигнатурой 55 AA в конце. В этом цикле
символ печатается до проверки на ноль, поэтому завершающий 0 тоже уходит
на экран (как пустой символ).

Тот же загрузчик на новых возможностях:

    og 0x7C00
    b 16

    start:
        xor ax - ax
        mov ds - ax
        call print - "Hello from Gasem!\r\n"
        call print - "Strings live in the pool below."
        jmp $

    ; print: печать строки si через BIOS
    args print - si
    print:
        push ax - si
        while 1
            nxtb
            break if al = 0
            mov ah - 0x0E
            int 0x10
        end
        pop ax - si
        ret

    pool
    && 510-($-$$) b: 0
    w: 0xAA55

Выражения do:

    do "[msg]" - si          si -> "Hello"
    do "[msg] + 1" - si      si -> "Hello1"
    do "[msg] + [f]" - si    si -> "HelloWorld"
    do "4+4" - ax            ax = 8

Переход в защищённый режим — examples/pmode.gsm.
Целая операционная система — папка os/ (GasemOS).


19. ЗАРЕЗЕРВИРОВАННЫЕ СЛОВА
--------------------------
Не могут быть именами меток и констант:
    регистры, b w d q s, byte word dword qword, short near far, a20,
    og align include incbin do equ pool args.

Слова if elif else end while for repeat until break continue let
работают как управляющие только в начале строки; метку с таким именем
можно объявить через двоеточие (end:), но лучше так не делать.


20. ШПАРГАЛКА
-------------
og 0x7C00 / b 16 / b 32      адрес загрузки, режим
mov a - b                    операнды через " - "
nxtb / chk / jfnz            lodsb / test / jnz
msg s: "текст"               строка с нулём
buf b-512                    512 нулевых байт
&& 510-($-$$) b: 0           добить до 510 байт
w: 0xAA55                    подпись загрузочного сектора
X = 5                        константа
.loop:                       локальная метка
if / elif / else / end       ветвление
while / for / repeat-until   циклы
ret if carry                 команда с условием
let eax - "ebx*2 + [x]"      вычисление во время работы
do "[msg] + 1" - si          вычисление при компиляции
call puts - "текст"          вызов с аргументом-строкой
args puts - esi              регистр аргумента
pool                         сюда — строки из команд
push eax - ebx               несколько регистров
mov a20 - 1                  включить A20
