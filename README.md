# Gasem

**Gasem** — компилируемый язык для написания загрузчиков и системного ПО.
Синтаксис в стиле ассемблера x86, но операнды разделяются **дефисом**, а не запятой:

```
mov ax - 1
```

Компилятор `gasem` превращает исходник `.gsm` прямо в машинный код x86
(16 и 32 бит) — в плоский двоичный файл, который можно записать в загрузочный
сектор и запустить. Ассемблер (NASM и т. п.) не нужен.

## Быстрый старт

Нужен только Python 3.8+ (без сторонних библиотек).

```sh
python3 -m gasem examples/hello.gsm                # → examples/hello.bin (512 байт)
qemu-system-i386 -drive format=raw,file=examples/hello.bin
```

или сразу собрать и запустить в QEMU:

```sh
python3 -m gasem examples/hello.gsm --run
```

Установка как команды `gasem`:

```sh
pip install .
gasem boot.gsm -o boot.bin
```

### Параметры командной строки

| Параметр            | Что делает                                                    |
|---------------------|---------------------------------------------------------------|
| `-o файл`           | выходной файл (по умолчанию — имя исходника с `.bin`)          |
| `-l файл`           | листинг: адрес, байты машинного кода и строка исходника        |
| `--run`             | после компиляции запустить результат в QEMU                    |
| `-q`                | не печатать сообщение об успешной компиляции                   |
| `-V`, `--version`   | версия компилятора                                             |

| Файл                                      | Что показывает                                                 |
|-------------------------------------------|----------------------------------------------------------------|
| [`examples/hello.gsm`](examples/hello.gsm) | загрузчик из документации: печатает `Hello` через BIOS         |
| [`examples/do.gsm`](examples/do.gsm)       | выражения `do` со строками и числами, локальные метки, `call`  |

# Документация языка

## Общее

- Исходник — текстовый файл в UTF-8, обычно с расширением `.gsm`.
- Одна команда на строку. Комментарий начинается с `;` и идёт до конца строки.
- Имена команд, регистров и директив не зависят от регистра букв (`MOV` = `mov`),
  имена меток — зависят.
- Регистры: `al cl dl bl ah ch dh bh`, `ax cx dx bx sp bp si di`,
  `eax ecx edx ebx esp ebp esi edi`, сегментные `es cs ss ds fs gs`,
  управляющие `cr0 cr2 cr3 cr4`, отладочные `dr0`–`dr7`.

### Разделитель операндов

Операнды разделяются **дефисом, окружённым пробелами**: ` - `.

```
mov ax - bx          ; два операнда
imul ax - bx - 10    ; три операнда
mov ax - -1          ; второй операнд — число -1
```

Дефис **без пробелов** — это минус: `510-($-$$)`. Внутри скобок `( )` и `[ ]`
дефис всегда означает минус, поэтому можно писать `[bx - 2]` или `(a - b)`.
Запятая — ошибка (компилятор подскажет).

### Числа и строки

| Запись                    | Значение                                   |
|---------------------------|--------------------------------------------|
| `1234`, `1_000`           | десятичное                                 |
| `0x7C00`, `0FFh`          | шестнадцатеричное                          |
| `0b1010`, `0o17`          | двоичное, восьмеричное                     |
| `'A'`, `"AB"`             | символы как число: `'A'` = `0x41` (до 8 байт, младший — первый) |
| `"Hello"`                 | строка (в данных и в `do`)                 |

В строках работают escape-последовательности: `\n \r \t \0 \\ \" \' \xNN`.
Строки кодируются в UTF-8.

## Метки и константы

```
start:                ; метка — адрес следующей команды
loop: dec cx          ; метка и команда на одной строке
msg b: "Hello" - 0    ; переменная: метка без двоеточия перед данными
.next:                ; локальная метка — принадлежит последней глобальной
SIZE = end - start    ; константа (то же: SIZE equ end - start)
```

- Ссылаться можно и вперёд, и назад — компилятор делает столько проходов, сколько нужно.
- Локальная метка `.next` после глобальной `print` на самом деле называется
  `print.next`; так к ней можно обратиться из другого места.
- В именах можно использовать буквы любого алфавита (в том числе кириллицу), цифры, `_` и `.`.
- Зарезервированы (не могут быть именами): регистры, `b w d q`, `byte word dword qword`,
  `short near far`, `a20`, `og align include incbin do equ`.

## Директивы

| Директива                         | Значение                                                 |
|-----------------------------------|----------------------------------------------------------|
| `og 0x7C00`                       | адрес загрузки (org). Один раз, до первой команды         |
| `b 16` / `b 32`                   | режим процессора (bits). Можно переключать по ходу программы |
| `align N`                         | выровнять адрес до кратного N (заполнение — `nop`)        |
| `align N - байт`                  | то же, заполнить указанным байтом                         |
| `include "файл.gsm"`              | вставить текст другого файла                              |
| `incbin "файл"`                   | вставить двоичный файл как есть                           |
| `incbin "файл" - смещение - длина`| вставить часть двоичного файла                            |

Пути в `include`/`incbin` считаются от папки текущего исходника.

## Команды

### Команды Gasem

| Gasem          | x86        | Описание                              |
|----------------|------------|---------------------------------------|
| `mov ax - 1`   | `mov`      | переместить                           |
| `xor ax - ax`  | `xor`      | исключающее ИЛИ                       |
| `int 0x10`     | `int`      | прерывание                            |
| `nxtb`         | `lodsb`    | следующий байт: `al = [si]`, `si += 1` |
| `nxtw`, `nxtd` | `lodsw`, `lodsd` | следующее слово / двойное слово |
| `chk al - al`  | `test`     | проверка (логическое И без записи результата) |
| `jfnz метка`   | `jnz`      | переход, если не ноль                 |
| `jmp $`        | `jmp`      | безусловный переход (`$` — сама эта строка, т. е. вечный цикл) |

Условные переходы Gasem: `jf` + условие. Все варианты:
`jfz jfnz jfe jfne jfc jfnc jfa jfae jfb jfbe jfg jfge jfl jfle jfs jfns jfo jfno jfp jfnp`
(а также синонимы `jfna jfnb jfnae jfnbe jfng jfnl jfnge jfnle jfpe jfpo`).
Стандартные имена x86 (`jnz`, `lodsb`, `test`) тоже работают.

### Остальные команды x86

| Группа              | Команды |
|---------------------|---------|
| пересылка           | `mov xchg lea movzx movsx lds les lss lfs lgs push pop pusha popa pushad popad pushf popf pushfd popfd` |
| арифметика          | `add adc sub sbb cmp inc dec neg mul imul div idiv cbw cwde cwd cdq daa das aaa aas` |
| логика и сдвиги     | `and or xor not test shl sal shr sar rol ror rcl rcr` |
| биты                | `bt bts btr btc bsf bsr bswap set<усл> cmov<усл>` |
| переходы и вызовы   | `jmp call ret retf iret iretd j<усл> loop loope loopne jcxz jecxz int int3 into enter leave` |
| строковые           | `movsb/w/d cmpsb/w/d stosb/w/d lodsb/w/d scasb/w/d insb/w/d outsb/w/d` с префиксами `rep repe repz repne repnz` |
| порты               | `in out` |
| флаги               | `cli sti cld std clc stc cmc lahf sahf` |
| системные           | `lgdt lidt sgdt sidt lldt sldt ltr str lmsw smsw invlpg clts hlt cpuid rdtsc rdmsr wrmsr wbinvd invd ud2 nop pause wait xlatb` |

### Операнды

```
mov ax - bx                  ; регистр
mov ax - 0x1234              ; число или выражение
mov si - msg                 ; адрес метки
mov ax - [msg]               ; память по адресу
mov al - [bx+si+4]           ; 16-битная адресация: bx/bp + si/di + смещение
mov eax - [ebx+ecx*4+8]      ; 32-битная адресация с масштабом 1, 2, 4, 8
mov ax - [es:di]             ; сегмент (можно и так: es:[di])
mov byte [bx] - 5            ; размер, если его нельзя понять из регистра:
mov word [bx] - 5            ;   byte / word / dword (коротко: b / w / d)
jmp short метка              ; принудительно короткий переход
jmp 0x08:pm_start            ; дальний переход сегмент:смещение
jmp far [ptr]                ; дальний переход по адресу в памяти
rep stosb                    ; префиксы rep, lock, es/cs/ss/ds/fs/gs
mov cr0 - eax                ; управляющие регистры
```

Короткие формы выбираются автоматически: переход занимает 2 байта, если цель
близко (−128…+127), иначе 3 (или 5 в `b 32`); число в `add bx - 5` кодируется
одним байтом и т. д. Машинный код совпадает байт в байт с NASM — это проверяется
тестами на сотнях форм команд.

## Порты (абстракции)

| Gasem          | Что делает                 |
|----------------|----------------------------|
| `mov a20 - 1`  | включить линию A20         |
| `mov a20 - 0`  | выключить линию A20        |

Используется «быстрый» способ через системный порт `0x92`. Регистр `ax`
(`eax` в `b 32`) сохраняется. `mov a20 - 1` разворачивается в:

```
push ax
in al - 0x92
or al - 2        ; бит 1 — A20
and al - 0xFE    ; бит 0 (сброс машины) никогда не ставим
out 0x92 - al
pop ax
```

## Данные

| Запись           | Что получается                                                  |
|------------------|-----------------------------------------------------------------|
| `b:`             | 0 байт — только метка (буфер, который «растёт» за конец программы) |
| `b: "Hello"`     | байты по содержимому: `48 65 6C 6C 6F`                          |
| `b: "Hello" - 0` | несколько значений через ` - `: строка и нулевой байт           |
| `b-N`            | ровно N байт, заполненных нулями                                |
| `b/ N: значения` | ровно N байт, начало заполняется значениями, остаток — нулями. Инициализация обязательна, N > 0, значения не длиннее N |
| `w:` `w-N` `w/ N:` | то же для слов (2 байта)                                      |
| `d:` `d-N` `d/ N:` | то же для двойных слов (4 байта)                              |
| `q:` `q-N` `q/ N:` | то же для 8-байтных значений (удобно для GDT)                 |
| `&& N b: 0`      | повторение: любая строка данных или команда N раз              |
| `w: 0xAA55`      | слово (байты `55 AA`)                                           |

Перед данными можно поставить имя переменной: `msg b: "Hello" - 0`,
`buf b-512`, `count w: 0`. Числа, не помещающиеся в элемент, — ошибка.

## Выражения

Операторы (от низшего приоритета к высшему):

| Приоритет | Операторы          |
|-----------|--------------------|
| 1         | `\|`               |
| 2         | `^`                |
| 3         | `&`                |
| 4         | `<<` `>>`          |
| 5         | `+` `-`            |
| 6         | `*` `/` `%`        |
| 7         | унарные `-` `+` `~`|

- `$` — адрес текущей строки, `$$` — адрес начала программы (значение `og`).
- `510-($-$$)` — сколько байт осталось до сигнатуры загрузочного сектора.

## Выражения do

```
do "выражение" - приёмник
```

Кавычки обязательны. Выражение **вычисляется при компиляции**, результат
кладётся в приёмник (регистр или память):

- если результат — **число**, получается `mov приёмник - число`;
- если результат — **строка**, компилятор помещает её прямо в код (с переходом
  в обход и завершающим нулём), а в приёмник записывает **адрес** строки.
  Одинаковые строки хранятся один раз.

Внутри выражения:

| Запись   | Значение                                                         |
|----------|------------------------------------------------------------------|
| `[msg]`  | всё значение переменной `msg`, как оно объявлено (строка — целиком, до нулевого байта; одно число — число) |
| `msg`    | адрес                                                            |
| `+`      | для чисел — сложение, для строк — конкатенация (число превращается в текст) |
| `'текст'`| строковая константа                                              |
| `- * / % & \| ^ << >> ~` | только для чисел                                  |

Примеры (при `msg b: "Hello" - 0` и `f b: "World" - 0`):

| Gasem                   | Результат                     |
|-------------------------|-------------------------------|
| `do "4+4" - ax`         | `ax = 8`                      |
| `do "[msg]" - ax`       | `ax` → строка `"Hello"`       |
| `do "[msg] + 1" - ax`   | `ax` → строка `"Hello1"`      |
| `do "[msg] + [f]" - ax` | `ax` → строка `"HelloWorld"`  |
| `do "msg + 2" - si`     | `si = адрес msg + 2`          |

Регистры в выражении `do` использовать нельзя — оно вычисляется во время
компиляции, а не во время работы программы.

## Пример загрузчика

```
og 0x7C00
b 16
xor ax - ax
mov ds - ax
mov si - msg
print:
    mov ah - 0x0E
    nxtb
    int 0x10
    chk al - al
    jfnz print
    jmp $

msg b: "Hello" - 0
&& 510-($-$$) b: 0
w: 0xAA55
```

Результат — ровно 512 байт с сигнатурой `55 AA` в конце. Обратите внимание:
в этом цикле символ печатается *до* проверки на ноль, поэтому завершающий `0`
тоже уходит на экран (как пустой символ). Чтобы этого не было, проверяйте
перед печатью — как в [`examples/do.gsm`](examples/do.gsm):

```
print:
    mov ah - 0x0E
.next:
    nxtb
    chk al - al
    jfz .done
    int 0x10
    jmp .next
.done:
    ret
```

## Ошибки

Компилятор показывает файл, строку, саму строку и место ошибки, и по
возможности подсказывает, как исправить:

```
boot.gsm:4: ошибка: операнды разделяются ' - ' (дефис с пробелами), а не запятой
    mov ax, 1
          ^
boot.gsm:9: ошибка: отрицательное число повторений (-90): код не помещается в отведённое место (например, загрузочный сектор длиннее 510 байт)
    && 510-($-$$) b: 0
```

## Листинг

`gasem boot.gsm -l boot.lst` пишет таблицу «строка — адрес — байты — исходник»
и список всех меток с адресами:

```
4     00007C00  31C0                  xor ax - ax
5     00007C02  8ED8                  mov ds - ax
6     00007C04  BE127C                mov si - msg
```

## Устройство компилятора

| Файл                 | Назначение                                                      |
|----------------------|-----------------------------------------------------------------|
| `gasem/lexer.py`     | токены; распознаёт разделитель ` - ` по пробелам вокруг дефиса   |
| `gasem/parser.py`    | разбор строк: метки, директивы, данные, команды, операнды, `do`  |
| `gasem/expr.py`      | вычисление выражений (числа и строки)                           |
| `gasem/assembler.py` | многопроходная сборка: адреса меток, `&&`, данные, `do`, листинг |
| `gasem/x86.py`       | кодирование команд x86 в машинный код (ModRM/SIB, префиксы)     |
| `gasem/cli.py`       | командная строка                                                |

Можно использовать и из Python:

```python
from gasem import compile_source
code = compile_source('og 0x7C00\njmp $\n&& 510-($-$$) b: 0\nw: 0xAA55').code
```

## Тесты

```sh
python3 -m unittest discover -s tests
```

- `tests/test_language.py` — директивы, данные, `do`, метки, сообщения об ошибках;
- `tests/test_nasm.py` — более 400 форм команд в режимах 16 и 32 бит сверяются
  байт в байт с NASM (пропускается, если `nasm` не установлен);
- `tests/test_boot.py` — примеры запускаются в эмуляторе x86 и проверяется, что
  они напечатали / записали в видеопамять (нужен `pip install unicorn`, иначе
  пропускается).
- `tests/test_os.py` — GasemOS собирается, загружается в QEMU и выполняет
  команды (пропускается, если QEMU не установлен).
